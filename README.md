# Конфигуратор Zeekr 8X

Только конфигуратор: без шапки, логотипа, подвала и цен. Его собирают в сборку и встраивают в страницу модели на сайте.

Посмотреть: https://tema-mail.github.io/zeekr-8x-konfigurator/ (закрыт от индексации).
Локально: `python3 -m http.server 8933`, затем http://127.0.0.1:8933/

## Что выбирает человек
Версия (Max, Ultra, Ultra+, Shadow «Яоин»), батарея 55 или 70 кВт·ч, пакет помощи водителю H7 или H9, цвет кузова
(5, у Shadow – 3 своих), декор кузова (матовый хром, чёрный декор «Яое», пакет «Яое»), диски – все, что сейчас есть
в официальном конфигураторе: 21″ спортивные «Синъяо», «Шуанъяо», аэродинамические, 22″ «Хуэйяо» и чёрные «Яое»
(у Ultra+ – с амортизаторами CCD), у Shadow – 22″ кованые «Линбо» и чёрные «Яое» с 6-поршневыми Brembo;
20″ «Гуанъяо» – базовые, сейчас Zeekr по акции меняет их на 21″, в конфигураторе есть с пометкой.
Цвет салона, один или два передних экрана, у Shadow – спортивные ковши или комфортные кресла,
дополнительно – 6-местный салон, фаркоп, Naim, потолочный экран для задних, выдвижные пороги.
Правила совместимости – из официального конфигуратора Zeekr: выбор подстраивается сам.

## Картинки
Официальные рендеры Zeekr конкретной сборки (zeekrlife.com, раздел заказа): главный кадр без фона, три студийных ракурса
(спереди ¾, сбоку, сзади ¾) и салон. На картинке всегда тот цвет, декор, диски и лидары, которые выбраны.
158 сборок кузова × 4 кадра + 68 вариантов салона, всё в WebP: `img/zeekr-8x/ext/{H7|H9}_{цвет}_{декор}_{диски}--{вид}.webp`.

## Встраивание в сайт
Скопировать блок `<div class="z9" data-z9>…</div>` из `index.html`, подключить `css/konfigurator.css`,
`js/zeekr-data.js`, `js/konfigurator.js`, положить рядом папку `img/`. Движок общий для всех моделей Zeekr,
модель задаёт только `js/zeekr-data.js` и картинки. Цвета – токены `--z9-*` в начале CSS (светлая и тёмная тема).

Заявка «Отправить сборку менеджеру»: у формы атрибут `data-endpoint` – адрес приёма заявок сайта,
туда уходит POST JSON `{name, phone, text, url, lines, source, page}`. Пока он пустой, заявка уходит событием:
```js
document.querySelector('[data-z9]').addEventListener('zeekr:lead', e => send(e.detail));
// текущая сборка в любой момент: window.ZeekrCfg.get()  → {text, lines, config, url}
// каждое изменение: событие 'zeekr:change'
```
Ссылку на политику конфиденциальности вписать в `a[data-policy]` формы. Сборка хранится в адресе (`#v=55&o=…`).

## Как обновить данные
Инструменты в `tools/` (нужны Python 3, Playwright, Pillow; запросы идут с российского или китайского адреса –
zeekrlife.com не отвечает адресам из Европы):
1. `sniat-opcii.py 11 GMY_Z012_01` – открывает страницу заказа модели и снимает версии и опции через их API → `z9x-raw.json`;
2. `svod.py z9x-raw.json model.json` – правила совместимости и список нужных кадров → `model.json`;
3. `skachat.py model.json 11 raw` – скачивает кадры в `raw/` (6 потоков, повторы, ракурсы ищутся по всем версиям);
4. `kadry.py raw img/zeekr-8x` – WebP; `ikonki-dekora.py model.json img/zeekr-8x` – иконки декора из рендеров;
5. `dannye.py model.json js/zeekr-data.js "Zeekr 8X" 8X img/zeekr-8x 11` – данные для страницы (переводы названий в нём).

Данные сняты 11.11.2026, модель Zeekr 8X 2026 модельного года (modelInfoId 11).
